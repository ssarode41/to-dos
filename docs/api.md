# API Reference

## Health

GET /health

Returns a simple status payload for service monitoring.

## Todos

GET /api/v1/todos

Returns the list of todos.

POST /api/v1/todos

Creates a new todo.

PUT /api/v1/todos/:id

Updates a todo.

PATCH /api/v1/todos/:id/complete

Marks a todo as complete.

DELETE /api/v1/todos/:id

Deletes a todo.
